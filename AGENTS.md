# clone-tabnews-ia

## Definição do projeto

Recriação do [TabNews](https://www.tabnews.com.br) feita com ajuda de IA. O TabNews é a comunidade brasileira de conteúdo sobre tecnologia e programação, onde as pessoas publicam e comentam conteúdos.

## Stack

- Next.js 16 (App Router, diretório `app/`)
- React 19

## Comandos

- `npm run dev`: inicia o servidor de desenvolvimento
- `npm run build`: gera o build de produção
- `npm run start`: inicia o servidor de produção
